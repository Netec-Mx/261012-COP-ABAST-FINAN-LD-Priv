# IA Aplicada al abastecimiento estratégico en banca con Microsoft 365 Copilot

Programa práctico orientado a integrar IA generativa y Microsoft 365 Copilot en los procesos cotidianos de Abastecimiento de una entidad financiera. El curso utiliza un caso transversal de contratación de un servicio crítico de ciberseguridad administrada para recorrer investigación de mercado, sourcing, evaluación de propuestas, análisis económico, riesgo de terceros, negociación, contratos y automatización. Distribución: 85% práctica / 15% contenidos guiados. Casos de trabajo personalizados: seguridad - biometría facial para el grupo Cibest, contratación de servicios de IA y renovación de Contact Center, utilizando los datos y variables compartidos por el cliente.
